# Task template

Copy this block into a GitHub issue or task document. Keep one current handoff, not a growing transcript.

```text
ID / title:
Goal and player-facing outcome:
Project and affected systems/files:
Branch / workspace / baseline commit:
Current agent (temporary):
Dependencies and possible file conflicts:
Acceptance criteria:
- [Observable outcome and pass condition]
Required automated checks:
Required Unity/build/device/visual checks:
Status: ready | active | review | blocked | done
Handoff: changed files and commits; checks passed/failed/not run; known limits; next action
```
